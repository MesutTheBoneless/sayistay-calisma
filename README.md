# Sayıştay Çalışma Merkezi

17 günlük hızlandırılmış Sayıştay Denetçi Yardımcılığı çalışma programı için ücretsiz, statik ve bağımsız test sitesi.

## Özellikler

- 17 günlük program görünümü
- Gün bazlı ders ve konu başlıkları
- Şık seçildiğinde anında doğru/yanlış bilgisi
- Doğru cevap ve kısa açıklama
- Doğru / yanlış / kalan sayaçları
- İlerleme yüzdesi
- Test sonunda skor
- Yanlışları tekrar çözme
- Testi sıfırlama
- İlerlemenin tarayıcıda saklanması
- Mobil uyumlu arayüz

Program bilgileri ve sorular `data.js` içinde tutulur. Yeni gün eklemek için `quizzes` alanına ilgili gün numarasıyla test eklenmesi yeterlidir.
